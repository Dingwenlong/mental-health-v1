CARE DEBUGGING跟进功能排错

测试暴露的四类问题

01

医生越权风险

四个回访接口只按角色判断，没有同时核对当前负责人和分配版本。

修复：每次查询都校验当前负责人。
02

API 地址缺少前缀

客户端拼出的照护接口少了 /api/v1/，本地请求返回 404。

修复：统一由 API 客户端生成基础地址。
03

授权版本不一致

旧授权与新版本规则冲突，医生档案看不到趋势。

修复：通过正式接口撤回并重新授权。
04

Docker 环境过期

默认集成测试连接到过期 runtime socket，容器初始化失败。

处理：保留失败结果，改用本机隔离环境做完整流程。
