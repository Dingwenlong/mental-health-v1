# Task 18 结果页、重点观察和随访界面验收记录

日期：2026-08-24

## 本次完成内容

- Android 增加“咨询、结果、回访”三个底部入口。结果入口可按咨询编号查询进度，也可打开七题演示问卷。
- 结果页显示分析分数、非诊断提醒、已用资料、缺失资料、分数来源和随访安排。页面始终显示“这是比赛演示结果，不是诊断。需要医疗帮助时，请联系医生。”
- Android 随访页显示任务和时间。本地通知只写“回访提醒”和“你有一项演示回访安排”，不写风险等级、健康信息或对话内容。通知权限被拒绝时，任务仍留在页面上。
- 管理端增加分析任务、重点观察、随访日程和规则版本入口。重点观察支持级别、状态和“只看分配给我”筛选；详情显示分数、规则版本、资料质量、证据和缺失项。
- 医生修改关注级别、完成、改期、改派或取消随访时必须填写原因。没有合适号源时显示人工安排提示。
- 规则版本页写明“新设置只用于以后生成的结果，旧结果不会改变”。危机安全门固定开启，页面没有关闭入口。
- 后端增加 `/hubs/notifications`，发送 `AnalysisStatusChanged`、`RiskCaseChanged` 和 `FollowUpChanged`。事件只带编号、状态和修订号，不带对话或健康内容。

1. 概念图的深青、灰白和细边框配色已落地：主色 `#245D57`，深色侧栏 `#173F3A`，页面底色 `#F5F7F6`。
2. Android 保留“大分数、关注提示、非诊断说明、资料清单、分数解释、随访区”的上下顺序。
3. Android 底部固定为“咨询、结果、回访”，结果详情打开后仍保留这三个入口。
4. 管理端采用左侧固定导航、左侧队列和右侧详情。证据表与复核表单可以同时查看，避免在多个页面之间来回切换。
