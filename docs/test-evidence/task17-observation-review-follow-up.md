# 重点观察、医生复核和回访排程验证

日期：2026-08-24

## 本次实现

- L2、L3 和 Crisis 结果自动进入重点观察名单；L0、L1 不进入。真人咨询和 AI 虚拟人咨询使用同一条规则。
- 自动回访时限固定为：L1 七天、L2 72 小时、L3 24 小时。Crisis 不等待普通日程，立即进入人工处理队列。
- 只使用启用中的精神科医生时段。选择顺序固定为原服务医生、时段开始时间、未完成任务数、医生编号。
- 没有合格时段时，回访任务保持 `Proposed`，记录 `NO_QUALIFIED_SLOT_BEFORE_SLA` 和确切时限。系统不会安排到时限以后再显示成功。
- 已占用的时段不会再次进入自动候选名单。
- 医生复核会新增 `ClinicalReview`，保存复核等级、原因、医生和时间。原始 `RiskAssessment` 不修改。
- 改期、转派、取消和完成都要求填写原因。每次操作另写审计记录，保留操作人、对象、原因和时间。
- 普通用户只能查看自己的回访安排，不能进入医生的重点观察接口。医生可以按等级、状态和“分给我的”筛选队列。
- 重点观察详情同时返回原始结果、历次复核和回访状态，方便下一步管理端直接展示。
