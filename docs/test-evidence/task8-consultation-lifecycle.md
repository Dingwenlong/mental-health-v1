# 咨询生命周期验证

日期：2026-08-22

## 本次实现

- 普通用户可用已确认订单创建咨询；真人咨询必须分配可用的咨询师，AI 咨询不能分配咨询师。
- 文字咨询要求服务授权和分析授权；视频咨询还要求录音录像授权。
- 用户和本次咨询的咨询师可开始、查看、发送和完成咨询，其他用户和管理员不能读取消息。
- 消息按咨询单独编号。同一 `clientMessageId` 重试时返回原消息，不重复写入。
- 完成接口使用请求标识去重。同一请求重试不会再次产生 `ConsultationCompleted` 事件。
- 消息正文只写入 `messages` 表。应用日志只记录消息编号、咨询编号、顺序号和长度。
