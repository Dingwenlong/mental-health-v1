# Android AI 虚拟人、离线语音和危机页面验证

日期：2026-08-24

## 本次实现

- 已确认的 AI 文字咨询订单可以创建并启动 AI 会话，然后进入 Android AI 咨询页。
- 页面一直显示“你正在和 AI 虚拟人对话。它不是真人，也不是医生。”，不把虚拟人写成真人或医生。
- 二维角色由 Flutter 直接绘制，不使用人物图片。角色只有“等你说话”“正在听”“正在朗读”“请先联系求助电话”四种状态，不显示“诊断中”。
- 普通回复保留在消息列表中。客户端只选择已经安装、不需要网络的中文声音。
- 没有可用的中文离线声音时，客户端不使用网络声音，改为播放应用内的短提示音，并明确显示“没有可用的中文离线语音，回复已显示在屏幕上。”。
- 危机回复到达后立即停止上一段声音，角色切换到警示状态，输入框和发送按钮被移除，并显示 12356、120、110。
- 用户可见文案来自 `content/zh-CN/ui-copy.v1.json`，Flutter 和管理端生成文件已同步更新。

## Android 飞行模式验证

- 设备：Android 16 / API 36 模拟器 `emulator-5554`。
- 验收前保存飞行模式和 Wi-Fi 状态，并把恢复动作写入系统临时目录后回读确认。
- 验收期间开启飞行模式并关闭 Wi-Fi；向外网地址发起的探测失败。本机 API 只通过临时 ADB 端口映射访问。
- 模拟器报告中文语言 `zh-CN`、`zh-TW`，列出 9 个不需要网络的中文声音，但已安装数量为 0。因此本轮按规则走提示音和文字降级，没有使用网络声音。
- 普通合成消息返回规则回复并完成降级。危机合成消息“我已经准备好了工具，今晚就要结束生命”命中真实后端安全规则；页面显示心理援助 12356、医疗急救 120、报警求助 110，并移除普通输入框。
- 验收结束后回读：飞行模式为关闭，Wi-Fi 为开启，ADB 端口映射为 0，Task 13 临时目录为 0。

## 当前边界

- 本轮使用 Android 模拟器，不是实体手机。
- 模拟器没有安装中文离线音色，所以本轮验证的是“明确降级”路径；有已安装中文离线音色时的朗读路径由 Provider 测试覆盖，仍需在带该音色的实体 Android 手机上听感确认。
- 当前提示音只用于提醒用户查看屏幕文字，不代表语音回复。
- `flutter_tts` 和 `flutter_webrtc` 仍会提示未来需要迁移 Kotlin Gradle Plugin。当前静态检查、测试和 APK 构建均通过，升级 Flutter 或插件时需要重新验证。
