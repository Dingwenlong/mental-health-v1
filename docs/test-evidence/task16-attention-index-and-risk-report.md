# 关注指数与证据报告验证

日期：2026-08-24

## 本次实现

- 关注指数使用五项固定权重：问卷 45%、文字 25%、音频 15%、视频 5%、历史变化 10%。
- 缺少某项资料时，不补零，也不编造默认值。分数只在已有资料的权重内重新计算，同时返回缺失项和实际可用权重。
- 置信度按“权重 × 资料质量”相加，不因缺项重新放大。分数和资料质量会先限制在合法范围内。
- 默认等级分界为 25、50、75。明确危机命中时，不管数值多低，结果都保留 `Crisis` 和命中的规则编号。
- 每份结果保存分数、等级、置信度、规则版本、转写版本、缺失项和证据来源。分析任务完成后指向确切结果。
- 结果没有覆盖接口。管理员启用新规则后，旧结果仍保留原来的规则版本和计算值。
- 管理员只能新建规则版本和启用一个版本。权重必须合计为 1，等级分界必须递增，危机规则不能关闭。
- 规则切换放在一个数据库事务内。旧版先停用，新版再启用；任一步失败都会回滚。
- `GET /api/v1/results/{sessionId}` 先检查咨询访问权。测试确认咨询本人可以查看，其他普通用户不能查看。
- 报告固定显示“此结果不能替代诊断”。

## 心理问卷

- `DemoWellbeingScaleV1` 包含心情、担心、睡眠、精力、回避社交、无望感和安全七题。
- 回答使用 0、1、2、3 四档，总分按 `sum / 21 * 100` 转为 0–100。
- 安全题只作为会后分项。咨询中的明确危机文字仍由实时安全门立即处理。

## 数据库

- `20260824031335_AddRiskAssessments` 新增 `risk_rule_sets`、`risk_assessments` 和 `risk_evidence`。
- 数据库只允许一个启用中的规则版本。
- 同一咨询、规则版本和转写版本只保存一份结果。
- 证据随结果保存；删除规则或咨询不能顺带删除历史结果。
- 迁移已应用到本机 PostgreSQL，EF 模型没有待生成的迁移。
