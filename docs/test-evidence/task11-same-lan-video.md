# 同局域网真人视频咨询验证

日期：2026-08-22

## 本次实现

- Android 患者端在用户同意相机、麦克风和录音录像授权后进入真人视频咨询；拒绝权限时仍可返回文字咨询。
- 管理端咨询师在“视频咨询”页面输入咨询编号后进入同一房间。
- 两端通过 `/hubs/rtc` 交换 offer、answer 和 ICE candidate。WebRTC 配置 `iceServers: []`，本次只使用同局域网主机候选，不接入公网 STUN、TURN 或云 RTC。
- Android 在咨询期间录制患者本地画面和麦克风。咨询结束后按 1 MiB 分块上传，单块失败最多重试 3 次，完成时核对完整文件 SHA-256。
- 录像上传失败时页面明确提示联系工作人员，不把失败状态显示成上传成功。
- 浏览器或手机离开房间、连接失败和页面销毁时都会停止媒体轨、关闭连接并释放本地流。
- 本机 HTTPS 使用项目生成的开发根证书。Android 和 Flutter 只信任随应用打包的公开根证书，没有修改 Windows、Android 模拟器或用户级系统信任。

## 自动验证

- Flutter 静态检查：无问题。
- Flutter 测试：11 个通过。其中视频页 3 个，覆盖相机拒绝、连接失败和录像上传失败；录像上传器 2 个，覆盖空录像拒绝、1 MiB 分片、失败重试和完整摘要。
- Flutter 调试 APK 构建通过。
- Vue 测试：7 个通过。其中视频房 3 个，覆盖连接成功、连接失败和相机启动期间关闭页面；生产构建通过。
- 后端单元测试：72 个通过。
- 后端合同测试：76 个通过。
- 后端集成测试：51 个通过。

## Android 与浏览器联调

- Android API 36 模拟器作为患者端，Chrome 作为咨询师端。
- 两端都观察到 WebRTC 已连接；管理端显示“视频已连接”，患者画面和咨询师画面同时可见。
- 本轮只使用合成相机和合成麦克风输入，没有真实患者、真实咨询师或真实音视频。
- 咨询结束后只生成 1 个最终媒体文件，大小为 107,680 字节，内容非空；临时分块已删除。
- 联调截图保存在 `tests/output/playwright/task11-video-connected.png`，该目录被 Git 忽略，不进入交付文件。
- Android 模拟器只通过临时端口映射访问本机 HTTPS API 和信令服务；WebRTC 媒体仍使用同局域网主机候选。验收结束后端口映射、任务进程和任务临时目录均为 0。

## 当前边界

- 仅支持同一局域网。跨网络、弱网切换和运营商网络需要后续接入 TURN 后再验收。
- 当前只上传患者端本地录像，不合并咨询师远端画面。
- 本机服务证书有效期为 90 天；到期前需重新生成服务器证书。根证书私钥和服务器 PFX 不进入 Git。
