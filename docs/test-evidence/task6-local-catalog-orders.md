# 人员、套餐、时段和模拟订单验证

日期：2026-08-22

## 本次实现

- 管理员可新增、修改和停用咨询师、医生、可用时段和服务套餐。
- 用户可读取启用中的套餐、人员和未来可用时段。
- 套餐支持真人或 AI、文字或视频、免费或模拟收费。v1 不允许 AI 视频，返回 `PLAN_COMBINATION_UNSUPPORTED`。
- 免费订单创建后立即确认；模拟收费订单创建后处于 `AwaitingDemoPayment`，只有用户明确确认后才变为 `Confirmed`。
- 模拟支付使用本机 `DemoPaymentGateway`，不连接支付平台，不产生真实扣款。
- 同一用户重复提交相同订单幂等键时返回原订单，不重复建单。
- 时段使用 `[开始, 结束)` 判断冲突；相邻时段可保存，重叠时段返回 `AVAILABILITY_SLOT_CONFLICT`。
- 人员和套餐的新增、修改、停用，以及时段和订单操作均保留审计动作。

## 失败用例

实现前运行 `CatalogAndOrderTests`，8 类目录和订单场景均因端点不存在返回 404，确认测试能捕获缺失实现。

专项测试覆盖：

- 免费与模拟收费订单的初始状态。
- 模拟收费必须显式确认，重复确认不会重复调用支付 Provider。
- 重复订单幂等键返回同一订单。
- AI 视频套餐被拒绝。
- 重叠时段被拒绝，相邻时段可用并可停用。
- 普通用户不能调用管理员目录接口。
- 套餐和人员新增、修改、停用后，用户目录只显示启用记录。
- 管理操作写入审计。
- 虚构咨询师和医生账户的 `practitioner_id` 与人员目录主键一致。
- 已绑定登录账户的人员不能单独修改目录角色，防止令牌角色与排程资格不一致。
- 带 `+08:00` 的时段在入库前转为 UTC。
