# 客户端登录、目录、授权和模拟订单验证

日期：2026-08-22

## 本次实现

- Android 客户端支持普通用户登录、工作人员动态验证码、套餐目录、三项独立授权、免费或模拟收费订单，以及模拟收费确认。
- 管理端支持登录和动态验证码，可新增或停用套餐、咨询人员和可用时段。
- 管理端在发送请求前拒绝 AI 视频套餐，服务端也返回 `PLAN_COMBINATION_UNSUPPORTED`。
- 客户端只根据稳定错误码决定下一步，不读取 `title` 或 `detail` 判断业务分支。
- 两端中文文案来自 `content/zh-CN/ui-copy.v1.json`。生成脚本输出 Dart 和 TypeScript 文件，重复运行结果不变。
- 禁用词合同会检查词条和两端生产代码；缺少关键安全提示、重复键或缺失键都会让测试失败。
- 管理端只允许配置中的本机来源跨域访问 API。

## 失败用例

- Flutter 目录测试开始时因页面和仓储不存在而无法编译。
- Vue 目录测试开始时因 `CatalogView.vue` 不存在而失败。
- 中文词条合同开始时因 `JsonUiCopyCatalog` 不存在而失败。
- 管理端跨域预检开始时返回 405。
- 首次 Android 设备流程发现公开套餐类型输出为内部值 `AiVirtual`，客户端无法识别；公开值改为 `Ai` 后通过。

## 工具链说明

`flutter_secure_storage 11.0.0` 固定使用 `compileSdk 37`，但当前 Android SDK 管理器提供的平台标识为 `android-37.0`，Gradle 无法解析 `android-37`。项目精确锁定到 `10.3.1`，使用 `compileSdk 36`；v1 没有旧密钥资料需要迁移。

`flutter_tts` 和 `flutter_webrtc` 仍会提示未来需要迁移 Kotlin Gradle Plugin。当前构建和设备测试均通过，后续升级 Flutter 前需要复查。
